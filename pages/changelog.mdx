# Changelog

This page tracks notable updates to Mesrai during its early access phase.  
Mesrai is actively evolving, and changes may focus on correctness, stability,
and review quality as we refine the AI review pipeline.

---

## February 2026 — Early Access 🚧

### v0.4.0 — Review Pipeline Stabilization

#### ✨ Improvements

- Improved **review orchestration flow** for multi-file pull requests
- Better handling of **new PRs without historical snapshots**
- Refined **review strategy selection** to avoid shallow or skipped reviews
- More consistent **review summaries** across different PR sizes
- Improved internal error handling for partial review failures

#### 🧠 AI Review Enhancements

- Improved context selection for changed files
- Reduced cases where reviews return _no actionable feedback_
- Better prioritization of architectural and code-quality feedback
- Safer defaults for early-stage review depth

#### 🐛 Fixes

- Fixed cases where reviews were marked complete but produced no comments
- Resolved incorrect file selection during delta calculation
- Improved retry behavior when LLM responses are incomplete

---

## January 2026 — Early Access 🚧

### v0.3.0 — Strategy & Context Foundations

#### ✨ Improvements

- Introduced **pre-review gathering pipeline** for structured PR context
- Added initial **review strategy engine** (full, incremental, focused)
- Improved handling of **new files vs modified files**
- Better detection of test files and configuration files

#### 🧠 AI Review Enhancements

- More consistent multi-file context passing to the AI reviewer
- Reduced false positives in low-signal diffs
- Improved fallback behavior when full semantic context is unavailable

#### 🐛 Fixes

- Fixed skipped reviews on newly opened PRs
- Corrected incorrect file mapping during review planning
- Improved webhook reliability for rapid commit pushes

---

## December 2025 — Early Access 🚧

### v0.2.0 — Core Review System

#### 🚀 Initial Capabilities

- GitHub App integration (PR open / update triggers)
- Automated AI-powered PR reviews
- Inline review comments and PR summaries
- Basic quality and architecture feedback

#### 🧱 Platform Foundations

- Asynchronous review processing via queue system
- Stateless worker-based review execution
- Safe, read-only code analysis (no code modification)
- Organization and repository-level configuration support

---

## November 2025 — Early Access 🚧

#### 🎉 Initial Release
