Mesrai is built with security and privacy as core principles. We understand that your code is your most valuable intellectual property.

## Data Handling

### What We Access

When you connect a repository, Mesrai accesses:

- ✅ Source code in pull requests
- ✅ PR metadata (title, description, author)
- ✅ File change history for context
- ❌ We never access credentials or secrets
- ❌ We never store your code permanently

### Data Retention

| Data Type | Retention Period |
|-----------|-----------------|
| PR Analysis | 90 days |
| Review Comments | Until PR closed |
| Usage Metrics | 1 year |
| Audit Logs | 7 years |

### Code Storage

Your code is processed in memory and is **never permanently stored**:

```

                           │
                           ▼
                    ┌──────────────┐
```

## Privacy Controls

### Repository-Level Settings

Control what Mesrai can access:

```yaml
# mesrai.config.yaml
privacy:
  # Exclude sensitive directories
  exclude_paths:
    - "secrets/**"
    - "config/credentials/**"
    - "*.env*"

  # Disable analysis for sensitive files
  sensitive_patterns:
    - "**/*password*"
    - "**/*secret*"
    - "**/*key*"
```

### Team Privacy Settings

Administrators can configure organization-wide privacy:

- **Data residency** - Choose US or EU data centers
- **IP allowlisting** - Restrict access to specific IPs
- **SSO enforcement** - Require SSO for all team members
- **Audit logging** - Enable detailed access logs

## Security Features

### Vulnerability Detection

Mesrai scans for security vulnerabilities in your code:

```javascript
// ❌ SQL Injection vulnerability detected
const query = `SELECT * FROM users WHERE id = ${userId}`;

// ✅ Suggested fix
const query = 'SELECT * FROM users WHERE id = $1';
const result = await db.query(query, [userId]);
```

### Secret Detection

Automatic detection of accidentally committed secrets:

- API keys and tokens
- Database credentials
- Private keys
- OAuth secrets
