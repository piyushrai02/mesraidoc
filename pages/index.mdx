## Why Mesrai?

### 🚀 Ship Faster
AI-powered PR reviews that analyze your entire codebase in seconds, not hours. Get architectural insights and spot issues before they reach production.

### 🎯 Context-Aware
Unlike simple pattern matchers, Mesrai understands your codebase architecture, dependencies, and relationships between components.

### 💡 Intelligent Feedback
Receive actionable suggestions based on best practices, security vulnerabilities, and performance optimizations.

### 📊 Built for Scale
From startups to enterprises, Mesrai scales with your team. Handle hundreds of PRs per day with sub-5ms response times.

## Core Capabilities

- **GitHub Integration**: Seamless integration with GitHub Apps for automatic PR reviews
- **AI-Powered Analysis**: Advanced LLM-based code understanding with call graph mapping
- **Token Optimization**: Smart context selection to maximize review quality while minimizing costs
- **Enterprise Billing**: Flexible subscription plans with usage-based pricing via Stripe
- **High Performance**: Edge rendering, Redis caching, and optimized worker architecture

## Get Started in 30 Seconds

1. **Install GitHub App**: Add Mesrai to your repositories
2. **Create PR**: Open a pull request as usual
3. **Get AI Review**: Mesrai automatically analyzes and comments within seconds

```bash
# Or use our CLI
npx mesrai init
npx mesrai review --pr 123
```
