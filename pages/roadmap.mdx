# Product Roadmap

Mesrai is currently available in **free early access** and under active development.  
Our goal during this phase is to work closely with real engineering teams, validate
core workflows, and continuously improve review quality, performance, and reliability.

This roadmap outlines what is **available today**, what is **actively being built**,
and where Mesrai is heading next.

---

## Current Focus (Early Access)

These capabilities are available today and actively improving based on usage and feedback:

### Core AI Review Pipeline

- Pull request reviews triggered automatically via GitHub
- Context-aware analysis across multiple files
- Incremental review support for follow-up commits
- Review summaries with verdicts and inline comments

### Review Intelligence

- Code quality and maintainability analysis
- Security-focused checks for common risks
- Architecture-aware change detection (early stage)
- Review depth selection based on PR size and scope

### Reliability & Safety

- No source code storage beyond the review lifecycle
- Secure webhook handling and access controls
- Graceful degradation when reviews partially fail
- Transparent review execution status

> During early access, some reviews may be incomplete or skipped as we refine strategy
> selection and agent coordination.

---

## Near-Term Roadmap

### Q4 2025 🚀

#### Multi-Language Expansion

- Python, Java, Go, and Rust support
- Language-aware review heuristics
- Framework-sensitive suggestions (e.g., Django, Spring)

#### Security Enhancements

- Static analysis expansion (SAST-style checks)
- Dependency risk awareness
- Improved secret and credential detection

#### Team-Level Controls

- Organization and repository review settings
- Team-specific rules and thresholds
- Shared review standards across teams

---

## Mid-Term Roadmap

### Q1 2026 🎯

#### Self-Hosted & Private Deployments

- On-premise and isolated environments
- Air-gapped review execution
- Custom model routing (Enterprise)

#### Developer Experience

- VS Code and JetBrains IDE integrations
- Early feedback before PR creation
- Review previews inside the editor

#### Analytics & Insights

- Review quality trends over time
- Issue detection metrics
- Review turnaround and effectiveness tracking

---

## Longer-Term Vision

### Q2 2026 and Beyond ✨

- **Auto-Fix Suggestions**  
  Safe, reviewable code changes suggested directly in PRs

- **Cross-Repository Intelligence**  
  Learn from patterns across multiple services and teams

- **Architecture Advisor**  
  System-level insights for large-scale changes

- **Test Intelligence**  
  Test gap detection and test generation recommendations
