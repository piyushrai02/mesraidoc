## Why Use Mesrai in Your IDE?

### Catch Issues Before You Commit

Get AI-powered feedback as you write code — before it ever reaches a pull request. Mesrai analyzes your changes in real-time and surfaces potential issues directly in your editor.

### Key Benefits

| Feature | Description |
| --- | --- |
| **Multi-Agent Analysis** | 7 specialized agents cover security, performance, architecture, code quality, best practices, error handling, and maintainability |
| **Inline Diagnostics** | Native squiggly underlines and Problems panel entries — just like ESLint or TypeScript errors |
| **One-Click Fixes** | Lightbulb quick fixes applied automatically — no copy-pasting |
| **Four Review Modes** | Review & Commit, Review Uncommitted, Review Unpushed, and Review Current File |
| **Sidebar Dashboard** | Account status, review actions, findings list with severity badges, and review statistics |
| **Status Bar** | See review state at a glance — idle, reviewing, or open findings count |

### How It Works

1. **Install the extension** in your IDE
2. **Sign in** with your Mesrai account via the Command Palette
3. **Run a review** — right-click a file or use one of the four review modes
4. **See findings** as native inline diagnostics with severity levels
5. **Apply fixes** with one click via the lightbulb Quick Fix menu
