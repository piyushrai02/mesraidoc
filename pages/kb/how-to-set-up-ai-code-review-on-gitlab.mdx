Mesrai integrates with GitLab via OAuth and webhooks. Once configured, merge requests are reviewed automatically.

## Steps

1. **Create an account** at [mesrai.com](https://mesrai.com)
2. **Connect GitLab** — authorize via OAuth during setup
3. **Configure webhooks** — follow the guided setup to enable merge request events
4. **Select projects** — choose which GitLab projects Mesrai should review
5. **Open a merge request** — Mesrai reviews it automatically

## What you get

- Automated reviews on every MR
- Comments posted directly in the merge request
- Customizable rules and suggestion controls
- Business logic validation against linked tasks

## Custom configuration

Drop a `mesrai-config.yml` in your repo root to customize behavior per project.

For the full setup guide, see [GitLab OAuth](/operations/platforms/gitlab/gitlab_oauth) and [GitLab Webhooks](/operations/platforms/gitlab/gitlab_webhook).
