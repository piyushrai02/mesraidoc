## What Pulse is for

Pulse is the analytics surface inside Mesrai. It surfaces delivery metrics, code-quality signals, and AI-suggestion adoption rates so engineering leaders can see *how* the team ships, not just *what* it ships.

<Warning>
  Pulse ships with the **Teams** and **Enterprise** plans on cloud. Free Community workspaces don't include Pulse.
</Warning>

## Highlights

- Refresh cadence: every 2 hours
- Cloud-only, Teams + Enterprise tiers
- Metric calculation runs over the same data Mesrai's reviewer already sees
- Eight built-in DORA / quality / activity metrics out of the box

## Metric categories

- **Productivity** — deploy frequency, lead time, PR cycle time
- **Quality** — PR size distribution, review effectiveness
- **AI adoption** — Mesrai-suggestion implementation rate
- **Team performance** — collaboration patterns, bottleneck spotting

## How Pulse identifies developers

Pulse ties activity to the **Git commit username**. That may not match:

- GitHub / GitLab display name
- Email address
- Mesrai workspace login

<Tip>
  If a developer's numbers look off, check that their `git config user.name` is consistent across machines + their Git provider profile.
</Tip>
