# Integrations Overview

Mesrai integrates seamlessly with popular development tools and services to fit into your existing workflow.

## Available Integrations

### Version Control

#### GitHub
- **GitHub App**: Install our GitHub App for automatic PR reviews
- **Webhook Support**: Real-time PR notifications
- **OAuth Integration**: Secure authentication

#### GitLab
- **GitLab Integration**: Connect your GitLab repositories
- **Merge Request Reviews**: Automatic reviews on MRs
- **Self-Hosted**: Support for GitLab self-hosted instances

### Communication

#### Slack
- **Review Notifications**: Get notified when reviews are complete
- **Interactive Commands**: Trigger reviews from Slack
- **Channel Integration**: Post summaries to team channels

#### Discord
- **Bot Integration**: Add Mesrai bot to your server
- **Webhook Support**: Custom notification channels

### CI/CD

#### GitHub Actions
- **Pre-built Actions**: Easy integration with workflows
- **Custom Triggers**: Review on specific events

#### CircleCI
- **Orb Integration**: Use our CircleCI orb
- **Pipeline Integration**: Add reviews to your pipeline

### Project Management

#### Jira
- **Issue Linking**: Link reviews to Jira issues
- **Status Updates**: Automatic status sync

#### Linear
- **Issue Integration**: Connect reviews to Linear issues
- **Bi-directional Sync**: Keep everything in sync

## Coming Soon

- Bitbucket support
- Azure DevOps integration
- Microsoft Teams notifications
- Jenkins plugin
